# Keryx glossary

Use these terms, with these meanings, in code, docs, diagnostics and commit messages. The design is in
[docs/adr/0001-keryx-mediator.md](docs/adr/0001-keryx-mediator.md).

| Term                      | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Avoid                                                                            |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **request**               | A sealed (a struct always is), non-generic type implementing exactly one closing of `IRequest<TResponse>` (or `IRequest`, which is `IRequest<Unit>`) and no `IStreamRequest<>` closing (KRX024). Sent with `Send`; has exactly one handler, in the request's own assembly.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | command, query, message (as type names for the concept)                          |
| **stream request**        | A sealed (a struct always is), non-generic type implementing exactly one closing of `IStreamRequest<TItem>` and no `IRequest<>` closing (KRX024). Sent with `Stream`; has exactly one handler, in the stream request's own assembly, which returns `IAsyncEnumerable<TItem>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | streaming query, stream command                                                  |
| **request base**          | An abstract or closed (C# 15 `closed`) type implementing a request or stream request interface, the base of sealed requests or stream requests. Never a request itself: it has no handler (a handler that takes it is KRX003), and each of its sealed cases has its own.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | base request, polymorphic request                                                |
| **notification**          | A concrete, non-generic type implementing `INotification`. Sent with `Publish`; has zero or more handlers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | event, message, signal                                                           |
| **handler**               | The `private static Handle`/`HandleAsync` method that processes one request, stream request or notification.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | handler interface, `IRequestHandler`                                             |
| **handler class**         | The `partial` class that contains exactly one handler, and whose other half Keryx generates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | handler type (ambiguous), slice                                                  |
| **invoker**               | The generated public `InvokeAsync` on a handler class. Runs the handler only, with no behaviors. In a host, a handler with injected parameters also gets a **static entry**, `internal static __keryx_InvokeAsync`, the invoker with the injected services as parameters, which the host's pipeline contexts call so they never construct the class (owner decision 44).                                                                                                                                                                                                                                                                                                                                                                                        | wrapper, adapter                                                                 |
| **behavior**              | A `static` class, marked with one or more kind attributes, whose behavior methods wrap part of a pipeline; also called a **behavior class** when the class itself, not one of its kinds, is meant. Its kinds are request behavior, stream behavior and notification behavior. It declares exactly one behavior method for each kind attribute it carries; "X's behavior of a kind" means that method.                                                                                                                                                                                                                                                                                                                                                           | middleware, decorator, interceptor, filter, pipeline behavior                    |
| **behavior method**       | The `static` `Handle`/`HandleAsync` method a behavior class declares for a kind it carries. The generated pipeline calls it directly; its non-message parameters other than `next` and the `CancellationToken` are injected services.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | behavior instance, `Handle` override                                             |
| **kind attribute**        | One of `[RequestBehavior]`, `[StreamBehavior]` and `[NotificationBehavior]` on a behavior class. Says which kind of behavior method the class declares.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | behavior interface, marker interface                                             |
| **request behavior**      | A behavior marked `[RequestBehavior]`: wraps one `Send` of a request, calling `next` to run the rest of the pipeline.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | pipeline behavior, `IRequestPipelineBehavior`                                    |
| **stream behavior**       | A behavior marked `[StreamBehavior]`: wraps the inner stream of a stream request (from its `IStreamNext<T>` link) and returns the stream the caller enumerates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | wrap behavior, stream middleware                                                 |
| **notification behavior** | A behavior marked `[NotificationBehavior]`: wraps one whole `Publish` call, all handlers and the publish strategy included, also when the notification has no handlers. Notification handlers have no behaviors of their own.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | publish behavior, notification handler behavior, `INotificationPipelineBehavior` |
| **scope** (of a behavior) | Where a behavior is attached: per target (request or stream handler method, or notification type), per assembly, or global. Decides _whether_ it applies. Not the DI scope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | level, layer                                                                     |
| **phase**                 | The `Phase` enum value of a behavior class or, overriding it for one kind, of a behavior method. With `Order` and `RunsAfter`/`RunsBefore`, decides _where_ a behavior sits.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | stage, priority                                                                  |
| **pipeline**              | The ordered list of behaviors plus the handler (for a publish, the notification type's handlers) for one target, generated as straight-line code.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | chain, middleware stack                                                          |
| **link**                  | One generated `readonly struct` implementing `INext<T>`, `INext` or `IStreamNext<T>` at one position of a pipeline. Its primary constructor takes only what its `InvokeAsync` reads or passes on: the pipeline context (when there is one and it or a later link reads it) and the request or notification (unless nothing runs after it).                                                                                                                                                                                                                                                                                                                                                                                                                      | next delegate, continuation                                                      |
| **pipeline context**      | The generated per-scope object, kept in the scope state, holding, for one pipeline, the services its handler (or each handler) injects, or a referenced handler it constructs with `new` (handlers are never registered, owner decision 42), and the injected services of its behavior methods, each distinct service (type and key) once in a `ServiceN` field numbered by a stable sort of (type, key) (OQ-64), shared by every behavior method that injects it; the unkeyed `IServiceProvider` is the provider itself, in a `ServiceProvider` field (OQ-63). Only a pipeline that resolves or holds something has one (OQ-65, OQ-70); the links of one without a context, and the static publish strategy of such a publish pipeline, sit in a static class. | cache, holder                                                                    |
| **host**                  | A project whose `KeryxHost` MSBuild property is `true` (by default an executable, Android app or test project that targets .NET 10 or later). Gets the generated mediator and `AddKeryx()`, and composes every pipeline.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | app, entry assembly, root                                                        |
| **manifest**              | The compiled-metadata description of an assembly's Keryx contribution: `[assembly: KeryxManifest]`, a `[KeryxHandler]` attribute on each generated public handler class, and the public behavior classes (and their behavior methods) and notification types with their Keryx attributes (kind attributes, `[GlobalBehavior]`, `[BehaviorOrder]`, `[RunsAfter]`/`[RunsBefore]`, `[Behavior]`, assembly-level `[Behavior]`).                                                                                                                                                                                                                                                                                                                                     | registry, index                                                                  |
| **contracts assembly**    | An assembly that declares notifications (and shared types) for other assemblies to handle. It declares no requests: a request's handler lives in the request's own assembly (KRX001, KRX023).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | shared assembly, DTO assembly                                                    |
| **mediator**              | The generated `KeryxMediator` implementing `IMediator` (`ISender` + `IPublisher`) in a host. Transient: each resolve is a new, small instance over the scope, and every mediator of a scope shares its scope state.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | bus, dispatcher                                                                  |
| **scope state**           | The generated scoped `KeryxMediator.__KeryxScopeState` that holds one scope's pipeline contexts, one field per pipeline with a context, shared by every mediator resolved in the scope and resolved by a mediator's first call that needs a context (owner decision 46). Not the DI scope itself.                                                                                                                                                                                                                                                                                                                                                                                                                                                               | mediator cache, scope cache                                                      |

Diagnostic IDs use the `KRX` prefix (`KRX001`). Never `MED`.
