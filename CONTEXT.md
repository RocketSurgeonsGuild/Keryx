# Keryx glossary

Use these terms, with these meanings, in code, docs, diagnostics and commit messages. The design is in
[docs/adr/0001-keryx-mediator.md](docs/adr/0001-keryx-mediator.md).

| Term                              | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                         | Avoid                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **request**                       | A concrete (non-abstract), non-generic type implementing exactly one closing of `IRequest<TResponse>` (or `IRequest`, which is `IRequest<Unit>`) and no `IStreamRequest<>` closing. Sent with `Send`; has exactly one handler.                                                                                                                                                                                                  | command, query, message (as type names for the concept)            |
| **stream request**                | A concrete (non-abstract), non-generic type implementing exactly one closing of `IStreamRequest<TItem>` and no `IRequest<>` closing. Sent with `Stream`; has exactly one handler, which returns `IAsyncEnumerable<TItem>`.                                                                                                                                                                                                      | streaming query, stream command                                    |
| **notification**                  | A concrete, non-generic type implementing `INotification`. Sent with `Publish`; has zero or more handlers.                                                                                                                                                                                                                                                                                                                      | event, message, signal                                             |
| **handler**                       | The `private static Handle`/`HandleAsync` method that processes one request, stream request or notification.                                                                                                                                                                                                                                                                                                                    | handler interface, `IRequestHandler`                               |
| **handler class**                 | The `partial` class that contains exactly one handler, and whose other half Keryx generates.                                                                                                                                                                                                                                                                                                                                    | handler type (ambiguous), slice                                    |
| **invoker**                       | The generated public `InvokeAsync` on a handler class. Runs the handler only, with no behaviors.                                                                                                                                                                                                                                                                                                                                | wrapper, adapter                                                   |
| **behavior**                      | A `static` class, marked with one or more kind attributes, whose behavior methods wrap part of a pipeline; also called a **behavior class** when the class itself, not one of its kinds, is meant. Its kinds are request behavior, stream behavior, publish behavior and notification handler behavior. It declares exactly one behavior method for each kind attribute it carries; "X's behavior of a kind" means that method. | middleware, decorator, interceptor, filter, pipeline behavior      |
| **behavior method**               | The `static` `Handle`/`HandleAsync` method a behavior class declares for a kind it carries (one `INext` method serves both notification kinds, OQ-53 interim). The generated pipeline calls it directly; its non-message parameters other than `next` and the `CancellationToken` are injected services.                                                                                                                        | behavior instance, `Handle` override                               |
| **kind attribute**                | One of `[RequestBehavior]`, `[StreamBehavior]`, `[PublishBehavior]` and `[NotificationHandlerBehavior]` on a behavior class. Says which kind of behavior method the class declares.                                                                                                                                                                                                                                             | behavior interface, marker interface                               |
| **request behavior**              | A behavior marked `[RequestBehavior]`: wraps one `Send` of a request, calling `next` to run the rest of the pipeline.                                                                                                                                                                                                                                                                                                           | pipeline behavior, `IRequestPipelineBehavior`                      |
| **stream behavior**               | A behavior marked `[StreamBehavior]`: wraps the inner stream of a stream request (from its `IStreamNext<T>` link) and returns the stream the caller enumerates.                                                                                                                                                                                                                                                                 | wrap behavior, stream middleware                                   |
| **publish behavior**              | A behavior marked `[PublishBehavior]`: wraps one whole `Publish` call, all handlers and the publish strategy included, also when the notification has no handlers.                                                                                                                                                                                                                                                              | notification behavior (ambiguous), `INotificationPipelineBehavior` |
| **notification handler behavior** | A behavior marked `[NotificationHandlerBehavior]`: wraps the call of one notification handler, once per handler.                                                                                                                                                                                                                                                                                                                | notification behavior (ambiguous), handler behavior                |
| **scope** (of a behavior)         | Where a behavior is attached: per target (method or notification type), per assembly, or global. Decides _whether_ it applies. Not the DI scope.                                                                                                                                                                                                                                                                                | level, layer                                                       |
| **phase**                         | The `Phase` enum value of a behavior class or, overriding it for one kind, of a behavior method. With `Order` and `RunsAfter`/`RunsBefore`, decides _where_ a behavior sits.                                                                                                                                                                                                                                                    | stage, priority                                                    |
| **pipeline**                      | The ordered list of behaviors plus the handler for one target, generated as straight-line code.                                                                                                                                                                                                                                                                                                                                 | chain, middleware stack                                            |
| **link**                          | One generated struct implementing `INext<T>`, `INext` or `IStreamNext<T>` at one position of a pipeline. Holds the pipeline context and the request.                                                                                                                                                                                                                                                                            | next delegate, continuation                                        |
| **pipeline context**              | The generated per-scope object holding one pipeline's handler and the injected services of its behavior methods.                                                                                                                                                                                                                                                                                                                | cache, holder                                                      |
| **host**                          | An assembly marked `[assembly: KeryxHost]`. Gets the generated mediator and `AddKeryx()`, and composes every pipeline.                                                                                                                                                                                                                                                                                                          | app, entry assembly, root                                          |
| **externally handled request**    | A request or stream request type a host names with `[assembly: ExternallyHandled]`: it is handled outside this host, so the host needs no handler for it.                                                                                                                                                                                                                                                                       | ignored request, unhandled request                                 |
| **manifest**                      | The compiled-metadata description of an assembly's Keryx contribution: `[assembly: KeryxManifest]`, a `[KeryxHandler]` attribute on each generated public handler class, and the public behavior classes (and their behavior methods) and notification types with their Keryx attributes (kind attributes, `[GlobalBehavior]`, `[BehaviorOrder]`, `[RunsAfter]`/`[RunsBefore]`, `[Behavior]`, assembly-level `[Behavior]`).     | registry, index                                                    |
| **contracts assembly**            | An assembly that declares requests or notifications but not their handlers, marked `[assembly: KeryxContracts]`.                                                                                                                                                                                                                                                                                                                | shared assembly, DTO assembly                                      |
| **mediator**                      | The generated `KeryxMediator` implementing `IMediator` (`ISender` + `IPublisher`) in a host.                                                                                                                                                                                                                                                                                                                                    | bus, dispatcher                                                    |

Diagnostic IDs use the `KRX` prefix (`KRX001`). Never `MED`.
