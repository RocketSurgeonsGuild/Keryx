# Keryx glossary

Use these terms, with these meanings, in code, docs, diagnostics and commit messages. The design is in
[docs/adr/0001-keryx-mediator.md](docs/adr/0001-keryx-mediator.md).

| Term                      | Meaning                                                                                                                                                                                                                                                                                                                                 | Avoid                                                   |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| **request**               | A concrete (non-abstract), non-generic type implementing exactly one closing of `IRequest<TResponse>` (or `IRequest`, which is `IRequest<Unit>`) and no `IStreamRequest<>` closing. Sent with `Send`; has exactly one handler.                                                                                                          | command, query, message (as type names for the concept) |
| **stream request**        | A concrete (non-abstract), non-generic type implementing exactly one closing of `IStreamRequest<TItem>` and no `IRequest<>` closing. Sent with `Stream`; has exactly one handler, which returns `IAsyncEnumerable<TItem>`.                                                                                                              | streaming query, stream command                         |
| **notification**          | A concrete, non-generic type implementing `INotification`. Sent with `Publish`; has zero or more handlers.                                                                                                                                                                                                                              | event, message, signal                                  |
| **handler**               | The `private static Handle`/`HandleAsync` method that processes one request, stream request or notification.                                                                                                                                                                                                                            | handler interface, `IRequestHandler`                    |
| **handler class**         | The `partial` class that contains exactly one handler, and whose other half Keryx generates.                                                                                                                                                                                                                                            | handler type (ambiguous), slice                         |
| **invoker**               | The generated public `InvokeAsync` on a handler class. Runs the handler only, with no behaviors.                                                                                                                                                                                                                                        | wrapper, adapter                                        |
| **behavior**              | A class implementing one Keryx behavior interface that wraps a handler call (`IRequestPipelineBehavior`, `IStreamPipelineBehavior`, `INotificationPipelineBehavior`, `INotificationHandlerPipelineBehavior`) or, for streams, observes it through hooks (`IStreamHookBehavior`).                                                        | middleware, decorator, interceptor, filter              |
| **scope** (of a behavior) | Where a behavior is attached: per target (method or notification type), per assembly, or global. Decides _whether_ it applies. Not the DI scope.                                                                                                                                                                                        | level, layer                                            |
| **phase**                 | The `Phase` enum value of a behavior. With `Order` and `RunsAfter`/`RunsBefore`, decides _where_ it sits.                                                                                                                                                                                                                               | stage, priority                                         |
| **pipeline**              | The ordered list of behaviors plus the handler for one target, generated as straight-line code.                                                                                                                                                                                                                                         | chain, middleware stack                                 |
| **link**                  | One generated struct implementing `INext<T>`, `INext` or `IStreamNext<T>` at one position of a pipeline. Holds the pipeline context and the request.                                                                                                                                                                                    | next delegate, continuation                             |
| **pipeline context**      | The generated per-scope object holding one pipeline's handler and behavior instances.                                                                                                                                                                                                                                                   | cache, holder                                           |
| **wrap behavior**         | A stream behavior implementing `IStreamPipelineBehavior`: gets the inner stream from its `IStreamNext<T>` link and returns the stream the outer behavior or the caller enumerates, usually by re-yielding it with `await foreach`.                                                                                                      | stream middleware, stream decorator                     |
| **hook behavior**         | A stream behavior implementing `IStreamHookBehavior`: observes a stream through `OnStartAsync`, `OnItem`, `OnCompleteAsync` and `OnErrorAsync` instead of wrapping it.                                                                                                                                                                  | stream observer, stream listener                        |
| **fused hook segment**    | One generated async iterator that runs every hook behavior of a run of adjacent hook behaviors, between two wrap behaviors or an end of the pipeline.                                                                                                                                                                                   | hook chain, hook group                                  |
| **host**                  | An assembly marked `[assembly: KeryxHost]`. Gets the generated mediator and `AddKeryx()`, and composes every pipeline.                                                                                                                                                                                                                  | app, entry assembly, root                               |
| **manifest**              | The compiled-metadata description of an assembly's Keryx contribution: `[assembly: KeryxManifest]`, a `[KeryxHandler]` attribute on each generated public handler class, and the public behavior and notification types with their Keryx attributes (`[GlobalBehavior]`, `[BehaviorOrder]`, `[Behavior]`, assembly-level `[Behavior]`). | registry, index                                         |
| **contracts assembly**    | An assembly that declares requests or notifications but not their handlers, marked `[assembly: KeryxContracts]`.                                                                                                                                                                                                                        | shared assembly, DTO assembly                           |
| **mediator**              | The generated `KeryxMediator` implementing `IMediator` (`ISender` + `IPublisher`) in a host.                                                                                                                                                                                                                                            | bus, dispatcher                                         |

Diagnostic IDs use the `KRX` prefix (`KRX001`). Never `MED`.
